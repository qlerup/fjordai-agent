Chat i Visual Studio Code

Tal med agenterne direkte ved din kode. Projekter og workflows hentes fra denne installation.

  1. Download og installer udvidelsen via Extensions → Install from VSIX.
  2. Kør FjordAI Agent: Connect to server.
  3. Indtast serveradressen og en forbindelsesnøgle, som du opretter herunder.
  4. Åbn en projektmappe, og kør FjordAI Agent: Open chat.

Kopiér nøglen til VS Code. En ny nøgle erstatter den tidligere.
